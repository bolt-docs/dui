# create-dui

## 0.2.0-next.0

### Minor Changes

- **New package: `create-dui`** — interactive scaffolder that bootstraps a new CLI
  project pre-wired with `@bdocs/dui`. Run `pnpm create dui` (or `npx create-dui`)
  to scaffold a TypeScript CLI with banner, box, spinner, prompts, logger and
  theme included, ready to build.
