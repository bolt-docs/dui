Los plugins de DUI extienden la librería principal con funcionalidad adicional.

## Plugins oficiales

| Paquete | Descripción |
|---------|-------------|
| [@dui-toolkit/plugin-markdown](/docs/v0.5.0/plugins/markdown) | Renderizar markdown con resaltado de sintaxis |
| [@dui-toolkit/plugin-chart](/docs/v0.5.0/plugins/chart) | Gráficos de barras, columnas, líneas, pastel y sparkline |
| [@dui-toolkit/plugin-image](/docs/v0.5.0/plugins/image) | PNG / JPG / GIF en la terminal |
| [@dui-toolkit/plugin-diff](/docs/v0.5.0/plugins/diff) | Diffs unificados, lado a lado y a nivel de palabra |
| [@dui-toolkit/plugin-qrcode](/docs/v0.5.0/plugins/qrcode) | Códigos QR escaneables en la terminal |

## Crear tu propio plugin

Consulta la [documentación de la API de Plugins](/docs/v0.5.0/api/plugin) para aprender cómo crear y registrar tus propios plugins.
