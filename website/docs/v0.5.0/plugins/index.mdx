DUI plugins extend the core library with additional functionality.

## Official plugins

| Package | Description |
|---------|-------------|
| [@dui-toolkit/plugin-markdown](/docs/v0.5.0/plugins/markdown) | Render markdown with syntax highlighting |
| [@dui-toolkit/plugin-chart](/docs/v0.5.0/plugins/chart) | Bar, column, line, pie, and sparkline charts |
| [@dui-toolkit/plugin-image](/docs/v0.5.0/plugins/image) | PNG / JPG / GIF in the terminal |
| [@dui-toolkit/plugin-diff](/docs/v0.5.0/plugins/diff) | Unified, side-by-side, and word-level diffs |
| [@dui-toolkit/plugin-qrcode](/docs/v0.5.0/plugins/qrcode) | Scannable QR codes in the terminal |

## Creating your own plugin

See the [Plugin API docs](/docs/v0.5.0/api/plugin) to learn how to create and register your own plugins.
