# `create-dui` — CLI scaffolder

`create-dui` scaffolds a minimal CLI project pre-wired with
`@bdocs/dui`: a banner greeting, a boxed message, a spinner-wrapped
task, and (optionally) interactive prompts and a table — plus
`package.json` with the bin wired, a strict `tsconfig.json`, and a
README with run instructions.

```bash
npx create-dui my-cli
# or locally
pnpm dlx create-dui my-cli
```

The scaffolder is **built on `@bdocs/dui` itself** — the questions are
asked with `input`/`select`/`multiselect` and the work runs under
`task()`.

## Flags

| Flag | Description |
| --- | --- |
| `[dir]` | Target directory (default: current directory) |
| `-n, --name <name>` | Package name (default: folder name) |
| `-p, --package-manager <pm>` | `npm` \| `pnpm` \| `yarn` \| `bun` |
| `-y, --yes` | Skip prompts, use defaults |
| `--no-prompts` | Omit the `input`/`select` example |
| `--no-table` | Omit the table example |
| `-h, --help` | Show help |

```bash
create-dui --yes --package-manager pnpm
```

## Programmatic API

```ts
import { scaffold } from 'create-dui'

const { dir, files } = await scaffold({
  targetDir: './my-cli',
  name: 'my-cli',
  packageManager: 'pnpm',
  features: { prompts: true, table: false },
})
```

| Field | Type | Default | Notes |
| --- | --- | --- | --- |
| `targetDir` | `string` | — | Where to create the project (must be empty/non-existent) |
| `name` | `string` | — | npm package name (validated) |
| `packageManager` | `"npm" \| "pnpm" \| "yarn" \| "bun"` | `"npm"` | Hints written into the README |
| `features.prompts` | `boolean` | `true` | Include the `input`/`select` example |
| `features.table` | `boolean` | `true` | Include the table example |
| `dryRun` | `boolean` | `false` | Report files without writing |

### Result

`{ dir, files }` — `files` is the list of written files:

- `package.json` — bin wired to the compiled output, `@bdocs/dui` dependency
- `tsconfig.json` — strict TypeScript
- `src/index.ts` — the CLI entry with live examples
- `README.md` — install/run instructions for the chosen package manager
- `.gitignore`

## Generated project

```bash
my-cli
├── package.json
├── tsconfig.json
├── src/
│   └── index.ts
├── README.md
└── .gitignore
```

```bash
cd my-cli && pnpm install && pnpm dev
```

## Notes

- `scaffold()` is pure — no prompts, no network. Call it from scripts,
  CI, or your own tooling.
- The generated project is a plain TypeScript CLI: `tsx` for dev,
  `tsc` for builds, zero framework opinions.
- Interactive mode requires a TTY; with `--yes` (or piped stdin) the
  defaults are used instead.
