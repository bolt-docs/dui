# `banner(text)` — ASCII-art banners

Renders text in the classic heavy-shadow figlet style — the look used across READMEs and CLI tools for splash screens, section headers, and build success screens. Letters kern exactly like real figlet (flush glyphs with the font's own internal spacing). Colors come from the `banner.text` theme slot or an explicit color, and plain mode swaps the glyphs to ASCII `#` with no ANSI.

```ts
import { banner } from '@bdocs/dui'

console.log(banner('CI', { fill: '#', color: 'green' }))
```

## Options

| Field | Type | Default | Notes |
| --- | --- | --- | --- |
| `fill` | `string` | native glyphs | Paint every non-space cell with this character (plain mode forces `#`) |
| `color` | `ColorStyle` | `theme.banner.text` | Foreground for the whole banner |
| `gap` | `string` | `""` | Extra separator between glyphs (the font's internal spacing handles kerning; ignored in `smush` layout) |
| `double` | `boolean` | `false` | Solid variant with each cell doubled |
| `layout` | `"flush" \| "smush"` | `"flush"` | Join glyphs side by side, or overlap them like figlet's universal smushing |

## Layouts

- **`flush`** (default) — glyphs sit side by side using the font's own internal padding, so letters kern exactly like real figlet.
- **`smush`** — glyphs slide left until their ink collides; the later glyph wins on collision, and spaces between words collapse to the font's hardblank width. This is figlet's *universal smushing* — `banner('HOLA', { layout: 'smush' })` is byte-identical to the real `figlet` output.

```ts
import { banner } from '@bdocs/dui'

// Figlet-style overlapping glyphs, white for dark themes
console.log(banner('CI', { layout: 'smush', color: 'white' }))
```

## API

| Function | Returns | Notes |
| --- | --- | --- |
| `banner(text, options?)` | `string` | Rows joined with newlines (6 per glyph, 7 with accents) |
| `bannerLines(text, options?)` | `string[]` | The rows as an array (embed in other layouts) |

## Glyphs

Covers all printable ASCII — `A–Z`, `a–z` (reusing the uppercase shapes, as is standard for figlet fonts), `0–9`, and punctuation — plus Spanish accented vowels (`á é í ó ú ñ Á É Í Ó Ú Ñ`), `Ü ü`, and the typographic marks `¿ ¡ € — –`. Accent marks and umlauts sit centered above their letters. Unknown characters render as a blank glyph.

```ts
import { banner } from '@bdocs/dui'

// Build-success screen
console.log(banner('DONE', { color: 'green' }))
console.log(banner('FAIL', { color: 'red' }))
```

## Theme slots

| Slot | Default | Notes |
| --- | --- | --- |
| `banner.text` | `bold` | Whole-banner color |

```ts
import { configure } from '@bdocs/dui'

configure({ theme: { banner: { text: 'cyan' } } })
```

## Notes

- Plain mode (screen readers, `NO_COLOR`, `TERM=dumb`) renders the banner with `#` fill and no color so log scrapers still see the text.
- The ANSI Shadow font is embedded — no network or external assets.
