## divider

```ts
divider(char?: string, len?: number): string
```

<Field name="char" type="string" default="'─'">Repeat character for the line.</Field>
<Field name="len" type="number" default="terminal width">Line length in columns.</Field>

Returns a horizontal line that fits the terminal width.

### Default

```ts
divider('─')        // gray solid line
```

<TerminalPreview command="divider()">
{`\x1b[90m───────────────────────────────────────────────────────────────────────────────\x1b[39m`}
</TerminalPreview>

### Double

```ts
divider('═', 30)    // gray double line
```

<TerminalPreview command={`divider('═', 30)`}>
{`\x1b[90m══════════════════════════════════\x1b[39m`}
</TerminalPreview>

### Dotted

```ts
divider('·', 20)    // gray dotted line
```

<TerminalPreview command={`divider('·', 20)`}>
{`\x1b[90m······················\x1b[39m`}
</TerminalPreview>

### Dashed

```ts
divider('-', 40)    // gray dashed line
```

<TerminalPreview command={`divider('-', 40)`}>
{`\x1b[90m------------------------------------------\x1b[39m`}
</TerminalPreview>

Both functions accept a `color` option to override the default gray color:

```ts
divider('─', 40, { color: '#ff6b6b' })
dividerLog('═', 24, { color: '#00aaff' })
```

<TerminalPreview command="node color-divider.js">
{`\x1b[38;2;255;107;107m──────────────────────────────────────────\x1b[39m`}
</TerminalPreview>

## dividerLog

```ts
dividerLog(char?: string, len?: number, opts?: { color?: ColorInput }): void
```

Prints the divider directly to stdout.

```ts
dividerLog()
dividerLog('·', 16)
dividerLog('═', 40, { color: '#00cc88' })
```
