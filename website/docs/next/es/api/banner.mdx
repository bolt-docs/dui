# `banner(text)` — banners de arte ASCII

Renderiza texto como letras grandes usando una fuente de píxeles 5×5 embebida — perfecto para splash screens, headers de sección y pantallas de build exitoso. Los colores vienen del slot `banner.text` del tema o de un color explícito, y el modo plain cambia el fill a `#` ASCII sin ANSI.

```ts
import { banner } from '@bdocs/dui'

console.log(banner('CI', { fill: '#', color: 'green' }))
```

## Opciones

| Campo | Tipo | Default | Notas |
| --- | --- | --- | --- |
| `fill` | `string` | `"█"` | Carácter de relleno de celda (el modo plain fuerza `#`) |
| `color` | `ColorStyle` | `theme.banner.text` | Foreground de todo el banner |
| `gap` | `string` | `"  "` | Separador entre glifos |
| `double` | `boolean` | `true` | Pinta cada celda de fuente como 2 columnas (aspecto cuadrado) |

## API

| Función | Devuelve | Notas |
| --- | --- | --- |
| `banner(text, options?)` | `string` | 5 filas unidas con saltos de línea |
| `bannerLines(text, options?)` | `string[]` | Las 5 filas como array (embebe en otros layouts) |

## Glifos

Cubre `A–Z`, `0–9` y puntuación común (`- _ ! ? : . , / + = * @`). Los caracteres desconocidos se renderizan como un glifo en blanco.

```ts
import { banner } from '@bdocs/dui'

// Pantalla de build exitoso
console.log(banner('DONE', { color: 'green' }))
console.log(banner('FAIL', { color: 'red' }))
```

## Slots de tema

| Slot | Default | Notas |
| --- | --- | --- |
| `banner.text` | `bold` | Color de todo el banner |

```ts
import { configure } from '@bdocs/dui'

configure({ theme: { banner: { text: 'cyan' } } })
```

## Notas

- El modo plain (screen readers, `NO_COLOR`, `TERM=dumb`) renderiza el banner con fill `#` y sin color para que los log scrapers sigan viendo el texto.
- La fuente 5×5 está embebida — sin red ni assets externos.
