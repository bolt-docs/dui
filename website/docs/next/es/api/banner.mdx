# `banner(text)` — banners de arte ASCII

Renderiza texto en el clásico estilo figlet con sombra pesada — el look que ves en READMEs y herramientas CLI para splash screens, headers de sección y pantallas de build exitoso. Las letras hacen kerning exactamente como el figlet real (glifos pegados con el espaciado interno de la propia fuente). Los colores vienen del slot `banner.text` del tema o de un color explícito, y el modo plain cambia los glifos a `#` ASCII sin ANSI.

```ts
import { banner } from '@bdocs/dui'

console.log(banner('CI', { fill: '#', color: 'green' }))
```

## Opciones

| Campo | Tipo | Default | Notas |
| --- | --- | --- | --- |
| `fill` | `string` | glifos nativos | Pinta cada celda no vacía con este carácter (el modo plain fuerza `#`) |
| `color` | `ColorStyle` | `theme.banner.text` | Foreground de todo el banner |
| `gap` | `string` | `""` | Separador extra entre glifos (el espaciado interno de la fuente hace el kerning; ignorado en el layout `smush`) |
| `double` | `boolean` | `false` | Variante sólida con cada celda duplicada |
| `layout` | `"flush" \| "smush"` | `"flush"` | Une los glifos lado a lado, o los superpone como el universal smushing de figlet |

## Layouts

- **`flush`** (default) — los glifos van lado a lado con el padding interno de la propia fuente, así las letras hacen kerning exactamente como el figlet real.
- **`smush`** — los glifos se deslizan a la izquierda hasta que su tinta choca; el glifo posterior gana en la colisión, y los espacios entre palabras se colapsan al ancho de hardblank de la fuente. Es el *universal smushing* de figlet — `banner('HOLA', { layout: 'smush' })` es byte a byte idéntico al output del `figlet` real.

```ts
import { banner } from '@bdocs/dui'

// Glifos superpuestos estilo figlet
console.log(banner('CI', { layout: 'smush' }))
```

## API

| Función | Devuelve | Notas |
| --- | --- | --- |
| `banner(text, options?)` | `string` | Filas unidas con saltos de línea (6 por glifo, 7 con acentos) |
| `bannerLines(text, options?)` | `string[]` | Las filas como array (embebe en otros layouts) |

## Glifos

Cubre todo el ASCII imprimible — `A–Z`, `a–z` (reusan las formas mayúsculas, como es estándar en las fuentes figlet), `0–9` y puntuación — más las vocales acentuadas en español (`á é í ó ú ñ Á É Í Ó Ú Ñ`), `Ü ü`, y las marcas tipográficas `¿ ¡ € — –`. Los acentos y la diéresis quedan centrados sobre su letra. Los caracteres desconocidos se renderizan como un glifo en blanco.

```ts
import { banner } from '@bdocs/dui'

// Pantalla de build exitoso
console.log(banner('DONE', { color: 'green' }))
console.log(banner('FAIL', { color: 'red' }))
```

## Slots de tema

| Slot | Default | Notas |
| --- | --- | --- |
| `banner.text` | `bold` | Color de todo el banner |

```ts
import { configure } from '@bdocs/dui'

configure({ theme: { banner: { text: 'cyan' } } })
```

## Notas

- El modo plain (screen readers, `NO_COLOR`, `TERM=dumb`) renderiza el banner con fill `#` y sin color para que los log scrapers sigan viendo el texto.
- La fuente ANSI Shadow está embebida — sin red ni assets externos.
