# `create-dui` — scaffolder de CLIs

`create-dui` genera un proyecto CLI mínimo pre-configurado con
`@bdocs/dui`: un banner de saludo, un mensaje en caja, una tarea con
spinner y (opcionalmente) prompts interactivos y una tabla — además de
`package.json` con el bin conectado, un `tsconfig.json` estricto y un
README con instrucciones de ejecución.

```bash
npx create-dui my-cli
# o localmente
pnpm dlx create-dui my-cli
```

El scaffolder está **construido sobre `@bdocs/dui`** — las preguntas se
hacen con `input`/`select`/`multiselect` y el trabajo corre bajo
`task()`.

## Flags

| Flag | Descripción |
| --- | --- |
| `[dir]` | Directorio destino (default: directorio actual) |
| `-n, --name <name>` | Nombre del paquete (default: nombre de la carpeta) |
| `-p, --package-manager <pm>` | `npm` \| `pnpm` \| `yarn` \| `bun` |
| `-y, --yes` | Omitir prompts, usar defaults |
| `--no-prompts` | Omitir el ejemplo de `input`/`select` |
| `--no-table` | Omitir el ejemplo de tabla |
| `-h, --help` | Mostrar ayuda |

```bash
create-dui --yes --package-manager pnpm
```

## API programática

```ts
import { scaffold } from 'create-dui'

const { dir, files } = await scaffold({
  targetDir: './my-cli',
  name: 'my-cli',
  packageManager: 'pnpm',
  features: { prompts: true, table: false },
})
```

| Campo | Tipo | Default | Notas |
| --- | --- | --- | --- |
| `targetDir` | `string` | — | Dónde crear el proyecto (debe estar vacío/no existir) |
| `name` | `string` | — | Nombre npm del paquete (validado) |
| `packageManager` | `"npm" \| "pnpm" \| "yarn" \| "bun"` | `"npm"` | Hints escritos en el README |
| `features.prompts` | `boolean` | `true` | Incluir el ejemplo de `input`/`select` |
| `features.table` | `boolean` | `true` | Incluir el ejemplo de tabla |
| `dryRun` | `boolean` | `false` | Reportar archivos sin escribirlos |

### Resultado

`{ dir, files }` — `files` es la lista de archivos escritos:

- `package.json` — bin conectado al output compilado, dependencia `@bdocs/dui`
- `tsconfig.json` — TypeScript estricto
- `src/index.ts` — el entry del CLI con ejemplos vivos
- `README.md` — instrucciones de install/run para el package manager elegido
- `.gitignore`

## Proyecto generado

```bash
my-cli
├── package.json
├── tsconfig.json
├── src/
│   └── index.ts
├── README.md
└── .gitignore
```

```bash
cd my-cli && pnpm install && pnpm dev
```

## Notas

- `scaffold()` es puro — sin prompts, sin red. Llémalo desde scripts,
  CI o tu propia tooling.
- El proyecto generado es un CLI TypeScript simple: `tsx` para dev,
  `tsc` para builds, cero opiniones de framework.
- El modo interactivo requiere TTY; con `--yes` (o stdin pipeado) se
  usan los defaults.
