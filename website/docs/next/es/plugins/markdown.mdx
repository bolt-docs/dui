import { md, mdRender, mdSyntax, mdInteractive, collectChecklist } from '@dui-toolkit/plugin-markdown'

`@dui-toolkit/plugin-markdown` renderiza Markdown a terminal con colores ANSI y resaltado
de sintaxis impulsado por **shiki** (highlighter singleton con carga lazy y caché
de resultados).

## md

```ts
md(text: string, options?: MdRenderOptions): Promise<string>
```

Parsea y renderiza markdown, retornando un string con secuencias ANSI.

```ts
const output = await md('# Hola **mundo**')
console.log(output)
```

### Opciones

| Campo | Tipo | Default | Descripción |
|---|---|---|---|
| `width` | `number` | terminal | Capa el ancho de render en columnas — bloques de código, tablas y párrafos se ajustan / truncan a él |
| `focusItem` | `number` | — | Interno: pinta el puntero `❯` en una fila de checklist (lo usa `mdInteractive`) |

```ts
// Ajusta un documento a un panel angosto
const output = await md('# Tablas anchas', { width: 40 })
```

Desde **v2**, las celdas de tabla renderizan markdown inline — `**negrita**`, `` `código` ``
y `[enlaces](url)` dentro de una `| celda |` se estilizan en vez de imprimirse como
source crudo (los encabezados siguen en bold).

## mdRender

```ts
mdRender(text: string): void
```

Parsea y renderiza markdown directamente a stdout.

```ts
mdRender(`# Título

- Item con **negrita**
- Item con \`código\`
`)
```

## mdSyntax

```ts
mdSyntax(code: string, lang?: string): Promise<string>
```

Resalta sintaxis usando shiki con el tema `min-dark`. Usa resaltado por palabras
clave como fallback cuando shiki no está disponible.

```ts
const resaltado = await mdSyntax('const x: number = 1', 'ts')
console.log(resaltado)
```

## Elementos soportados

| Elemento | Sintaxis | Render |
|----------|----------|--------|
| Heading 1–6 | `# texto` … `###### texto` | Coloreado por nivel (rojo → púrpura) |
| Negrita | `**texto**` | Bold |
| Itálica | `*texto*` | Itálica (dim) |
| Código inline | `` `código` `` | Azul sobre fondo oscuro |
| Enlace | `[label](url)` | Azul subrayado + hint URL |
| Imagen | `![alt](url)` | `[image: alt]` dim |
| Lista no ordenada | `- item` / `* item` | • bullets |
| Lista ordenada | `1. item` | Numerada |
| Checkbox | `- [x] hecho` | ✔ / ✘ |
| Bloque código | ```` ```lang … ``` ```` | Recuadro con lang + highlighting |
| Cita | `> texto` | Dim con barra │ |
| Tabla | `| col | col |` | Grilla con fila de encabezado |
| Separador | `---` | Línea divisoria |

```ts
import { md } from '@dui-toolkit/plugin-markdown'

const markdown = `
# Estado del Proyecto

**Build:** pasando
**Versión:** \`1.2.3\`

| Componente | Estado |
|------------|--------|
| Core       | ✅ |
| CLI        | ✅ |
| Docs       | 🚧 |

> Ship early, ship often.

\`\`\`ts
function hello(): void {
  console.log('Hola!')
}
\`\`\`
`

console.log(await md(markdown))
```

## mdInteractive — checklists interactivas (v2)

```ts
mdInteractive(text: string, options?: MdInteractiveOptions): Promise<MdInteractiveResult>
```

Renderiza el documento y deja que el usuario **alterne checkboxes** con el teclado —
ideal para listas de tareas, checklists de release o cualquier UI de agente que
necesite que un humano confirme pasos. Retorna el source de markdown actualizado, la
lista plana de items y el render resultante.

```ts
import { mdInteractive } from '@dui-toolkit/plugin-markdown'

const r = await mdInteractive(`# Release

- [ ] build pasa
- [x] tests verdes
- [ ] push del tag
`)

if (r.changed) {
  console.log(r.text)     // markdown con los checkboxes alternados
  console.log(r.output)   // render resultante
}
```

### Keymap

| Tecla | Acción |
|---|---|
| `j` / `↓` | Mueve el foco al siguiente checkbox |
| `k` / `↑` | Mueve el foco al checkbox anterior |
| `space` / `Enter` | Alterna el checkbox enfocado |
| `q` / `Esc` | Termina con el estado actual |
| `Ctrl+C` | Cancela — sin cambios (`cancelled: true`) |

La fila enfocada se marca con un puntero `❯` y video inverso. Sin TTY (o con
`disable: true`) renderiza estáticamente y retorna el estado original.

### Estructura del retorno

`MdInteractiveResult`:

| Campo | Tipo | Descripción |
|---|---|---|
| `output` | `string` | Markdown renderizado con los estados actuales |
| `items` | `ChecklistItem[]` | Items planos `{ checked, label, line }` en orden de documento |
| `text` | `string` | Source con los checkboxes alternados |
| `changed` | `boolean` | `true` cuando al menos un box difiere del input |
| `cancelled` | `boolean` | `true` cuando el usuario presionó `Ctrl+C` |

### collectChecklist

```ts
collectChecklist(text: string): ChecklistItem[]
```

Helper puro que aplana cada item `[ ]` / `[x]` con su índice de línea fuente — útil
para inspeccionar o pre-aplicar una checklist sin el loop interactivo:

```ts
import { collectChecklist } from '@dui-toolkit/plugin-markdown'

const items = collectChecklist('- [ ] todo\n- [x] hecho')
// [{ checked: false, label: 'todo', line: 0 }, { checked: true, label: 'hecho', line: 1 }]
```

```ts
import { usePlugin } from '@bdocs/dui'

usePlugin(markdownPlugin)
```
