# `grid(opts)` — column layout

## Live demo

<GridDemo />

---



Renders multiple text columns side-by-side on the same set of output rows. Every column is wrapped independently via `wrapAnsiWord` to honor its allocated width; the resulting column lines are then zipped together by row index — shorter columns pad with spaces so rows align.

```ts
import { grid } from "@bdocs/dui";

grid({
  columns: [
    { content: "left half", width: "1fr", align: "left" },
    { content: "right half", width: "1fr", align: "right" },
  ],
  width: 60,
  gap: 2,
});
```

## Options

| Field | Type | Default | Notes |
| --- | --- | --- | --- |
| `columns` | `number \| GridColumn[]` | — | `number` shorthand = N equal columns. |
| `width` | `number` | `min(terminalWidth(), 80)` | Total layout width. |
| `gap` | `number` | `2` | Horizontal gap (spaces) between columns. |

### `GridColumn`

| Field | Type | Default | Notes |
| --- | --- | --- | --- |
| `content` | `string \| string[]` | — | Body text. Arrays are joined with `\n` before wrapping. |
| `width` | `number \| "${n}fr"` | `"1fr"` | Fixed pixel width or flex units (`1fr`, `2fr`, …). |
| `align` | `"left" \| "center" \| "right"` | `"left"` | Aligns the cell inside its column width. |

## Algorithms

1. **Width allocation.** Fixed `width: number` columns take their pixels first. The remaining space is split across flex columns in the ratio of their `fr` units. Columns with `width: undefined` share equally with sibling auto columns.
2. **Independent wrapping.** Each column body is wrapped via `wrapAnsiWord` to its allocated width — a column at `12` chars wraps to N rows independently from a column at `20` chars.
3. **Row zip.** The tallest column dictates the output row count. Every output row draws line `i` of every column, padding shorter columns with `alignMode("left"|"center"|"right")`. The result is a multi-line string of fixed visible-length rows.

## When to use

- Two-pane layouts (file list on the left, file preview on the right).
- Side-by-side diffs where the body wraps erratically.
- Status matrices where column widths are predictable.

For interactive widget composition (e.g. a header with tabs and a footer with kbd hints), combine `grid()` with `tabs()` and `section()` instead of building layouts by hand.
