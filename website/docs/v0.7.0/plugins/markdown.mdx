`@dui-toolkit/plugin-markdown` renders Markdown to ANSI-colored terminal output, with
syntax highlighting powered by **shiki** (lazy-loaded, singleton highlighter with
result caching).

## md

```ts
md(text: string, options?: MdRenderOptions): Promise<string>
```

Parses and renders markdown, returning a string with ANSI escape sequences.

```ts
const output = await md('# Hello **world**')
console.log(output)
```

### Options

| Field | Type | Default | Description |
|---|---|---|---|
| `width` | `number` | terminal | Cap the render width in columns — code blocks, tables and paragraphs wrap / truncate to it |
| `focusItem` | `number` | — | Internal: paints the `❯` pointer on a checklist row (used by `mdInteractive`) |

```ts
// Fit a document into a narrow pane
const output = await md('# Wide tables', { width: 40 })
```

Since **v2**, table cells render inline markdown — `**bold**`, `` `code` ``, and
`[links](url)` inside a `| cell |` are styled instead of printed as raw source
(headers stay bold on top).

## mdRender

```ts
mdRender(text: string): void
```

Parses and renders markdown directly to stdout.

```ts
mdRender(`# Title

- Item with **bold**
- Item with \`code\`
`)
```

## mdSyntax

```ts
mdSyntax(code: string, lang?: string): Promise<string>
```

Syntax-highlights a code string using shiki with the `min-dark` theme. Falls back
to keyword-based highlighting when shiki is unavailable.

```ts
const highlighted = await mdSyntax('const x: number = 1', 'ts')
console.log(highlighted)
```

## Extensible languages system

The highlighter supports **14 languages** out of the box, each registered as a `LanguageDef` with aliases. You can add more by calling `createLanguage()` before initializing the highlighter.

### Built-in languages

| Language | Aliases |
|----------|---------|
| TypeScript | `ts`, `typescript` |
| JavaScript | `js`, `javascript`, `jsx` |
| JSON | `json` |
| HTML | `html` |
| CSS | `css` |
| Bash | `bash`, `sh`, `shell` |
| Python | `python`, `py` |
| YAML | `yaml`, `yml` |
| Rust | `rust`, `rs` |
| Go | `go`, `golang` |
| Java | `java` |
| Ruby | `ruby`, `rb` |
| C++ | `cpp`, `c++`, `cxx`, `cc` |
| Elixir | `elixir`, `ex`, `exs` |

### Add a custom language

```ts
import { createLanguage } from '@dui-toolkit/plugin-markdown'

createLanguage({
  id: 'graphql',
  aliases: ['gql'],
  shikiLang: 'graphql', // must be a Shiki bundled language
})
```

## Theming

Every markdown element has a dedicated theme slot. Customize colors via `configure({ theme: { markdown: { … } } })`:

```ts
configure({
  theme: {
    markdown: {
      heading1: '#ff6e6e',
      heading2: '#ffb450',
      codeInline: { fg: '#96c8ff', bg: '#282c34' },
      quoteBar: '#64788c',
      listBullet: '#888888',
      thematic: '#888888',
    },
  },
})
```

## Supported elements

| Element | Syntax | Render |
|---------|--------|--------|
| Heading 1–6 | `# text` … `###### text` | Colored by level (red → purple) |
| Bold | `**text**` | Bold |
| Italic | `*text*` | Italic (dim) |
| Inline code | `` `code` `` | Blue on dark background |
| Link | `[label](url)` | Underlined blue + URL hint |
| Image | `![alt](url)` | `[image: alt]` dimmed |
| Unordered list | `- item` / `* item` | • bullets |
| Ordered list | `1. item` | Numbered |
| Checkbox list | `- [x] done` | ✔ / ✘ |
| Code block | ```` ```lang … ``` ```` | Bordered box with lang + highlighting |
| Blockquote | `> text` | Dim with │ bar |
| Table | `| col | col |` | Grid with header row |
| Thematic break | `---` | Divider line |

```ts
import { md } from '@dui-toolkit/plugin-markdown'

const markdown = `
# Project Status

**Build:** passing
**Version:** \`1.2.3\`

| Component | Status |
|-----------|--------|
| Core      | ✅ |
| CLI       | ✅ |
| Docs      | 🚧 |

> Ship early, ship often.

\`\`\`ts
function hello(): void {
  console.log('Hi!')
}
\`\`\`
`

console.log(await md(markdown))
```

## mdInteractive — interactive checklists (v2)

```ts
mdInteractive(text: string, options?: MdInteractiveOptions): Promise<MdInteractiveResult>
```

Renders the document and lets the user **toggle checkboxes** with the keyboard —
useful for task lists, release checklists, or any agent UI that needs a human to
confirm steps. Returns the updated markdown source, the flattened item list, and the
rendered output.

```ts
import { mdInteractive } from '@dui-toolkit/plugin-markdown'

const r = await mdInteractive(`# Release

- [ ] build passes
- [x] tests green
- [ ] push tag
`)

if (r.changed) {
  console.log(r.text)     // markdown with the toggled checkboxes
  console.log(r.output)   // rendered output
}
```

### Keymap

| Key | Action |
|---|---|
| `j` / `↓` | Move focus to the next checkbox |
| `k` / `↑` | Move focus to the previous checkbox |
| `space` / `Enter` | Toggle the focused checkbox |
| `q` / `Esc` | Finish with the current state |
| `Ctrl+C` | Cancel — no changes (`cancelled: true`) |

The focused row is marked with a `❯` pointer and inverse video. Without a TTY (or
with `disable: true`) it renders statically and returns the original state.

### Return shape

`MdInteractiveResult`:

| Field | Type | Description |
|---|---|---|
| `output` | `string` | Rendered markdown with the current checkbox states |
| `items` | `ChecklistItem[]` | Flattened `{ checked, label, line }` items in document order |
| `text` | `string` | Source text with the toggled checkboxes |
| `changed` | `boolean` | `true` when at least one box differs from the input |
| `cancelled` | `boolean` | `true` when the user pressed `Ctrl+C` |

### collectChecklist

```ts
collectChecklist(text: string): ChecklistItem[]
```

Pure helper that flattens every `[ ]` / `[x]` item with its source line index —
handy when you want to inspect or pre-apply a checklist without the interactive loop:

```ts
import { collectChecklist } from '@dui-toolkit/plugin-markdown'

const items = collectChecklist('- [ ] todo\n- [x] done')
// [{ checked: false, label: 'todo', line: 0 }, { checked: true, label: 'done', line: 1 }]
```
